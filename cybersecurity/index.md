## 归档规则

1. **对话与操作内容**必须写入 `memory/` 下的记忆文件，不得只保留在对话中。
2. `memory/` 按 **月建立子文件夹**，命名格式：`YYMMDD`（示例：`260930`，对应 2026-09-30 当期）。
3. 月文件夹内按 **周建立记忆文件**，命名格式：`W01.md`、`W02.md` …（当月第 N 周）。
4. 示例路径：`memory/260930/W01.md`。
5. 同一周内的操作追加写入对应周文件；跨周则新建下一编号的周文件。
6. `project/` 存放可交付的项目产出；`doc/` 存放学习过程记录。三类内容不混放。
7. **`doc/` 命名规则**：按阅读顺序为文件夹/文件添加前缀 `字母+两位数字`，例如 `A01-Test`。
   - **字母** = 模块章节（A 安全基础 → G 进阶，见 `doc/A00-学习大纲.md`）。
   - **数字** = 模块内阅读顺序（`01`、`02`…）。
   - **文件夹** = 学习单元，如 `A01-安全导论与法律边界`。
   - **文件** = 章内小节，在父级前缀后再加小序号，如 `A01-01-法律与授权.md`。
   - 学习从 `A00` 开始，按字母与数字递增阅读。
