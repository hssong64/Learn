# A01-01 · 行业概览与职业路径

## 学习目标

- 了解网络安全行业主要角色与分工
- 结合前端背景，找到可切入的岗位路径
- 建立「安全是持续工程」而不是「黑客炫技」的认知

## 一、行业地图

| 方向 | 做什么 | 与你的距离 |
|------|--------|------------|
| Web 安全 / 渗透测试 | 发现并验证 Web 漏洞，输出报告 | 最近，前端优势明显 |
| 安全开发 / SDL | 在研发流程中内建安全 | 可平滑转型 |
| 代码审计 | 审源码找漏洞 | 需读多语言，Java/PHP/Go 更常见 |
| 应急响应 | 被打后止血、取证、复盘 | 偏运维/系统 |
| 红队 / 攻防演练 | 模拟真实攻击链 | 需渗透 + 内网 + 免杀 |
| 蓝队 / 防守 | 监测、加固、溯源 | 偏 SOC/运维 |
| 安全研究 | 0day、漏洞分析、攻防对抗 | 门槛高，周期长 |
| 合规 / 等保 / 风险 | 制度、审计、测评 | 偏文档与管理 |

## 二、常见岗位名称

- 渗透测试工程师（初级/中级/高级）
- Web 安全工程师
- 安全服务工程师
- 红队工程师 / 攻防工程师
- 甲方安全工程师（企业 SRC / 安全部）
- 安全研发（WAF、RASP、安全平台）

## 三、前端 → 安全的优势

1. **浏览器就是你的主场**：同源策略、CSP、CORS、Cookie、DOM 你天天摸。
2. **HTTP 全生命周期熟悉**：请求/响应、代理、缓存、鉴权头。
3. **能读业务代码**：比只会跑扫描器的人更能判断「这是不是真漏洞」。
4. **自动化能力**：写脚本、搭靶场、做批量验证都更快。

**短板需要补**：网络底层、操作系统、数据库攻击面、内网、权限模型、免杀。

## 四、建议成长路径（前端背景）

```text
安全开发/SDL 岗
    ↓ 同时刷 Web 靶场
初级渗透 / Web 安全
    ↓ 掌握完整流程 + 报告
中级渗透（可独立接项目）
    ↓ 选专精：内网 / 云 / 免杀 / 审计
高级 / 红队 / 专家
```

## 五、行业必备软素质

- **书面表达**：报告写不清楚，漏洞再严重也推不动修复
- **协作沟通**：和开发、运维、业务对齐，而不是「我黑了你」
- **自律**：无授权不动手，边界感是职业生命线
- **持续学习**：漏洞面变化快，吃老本会掉队
