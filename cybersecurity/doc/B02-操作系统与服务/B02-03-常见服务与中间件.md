# B02-03 · 常见服务与中间件

## 学习目标

- 认识 Web 栈常见组件及其漏洞类型
- 理解中间件解析、配置、反向代理安全
- 知道数据库/缓存/队列的暴露风险

## 一、Web 服务组件

| 组件 | 作用 | 常见问题 |
|------|------|----------|
| Nginx / Apache / IIS | 反代、静态、TLS | 配置错误、路径穿越、解析漏洞 |
| Tomcat / Nginx+php-fpm / Node | 应用运行时 | 默认口令、管理台、组件 CVE |
| WAF / CDN | 边缘防护 | 绕过、误配、真实 IP 泄露 |

### 经典解析问题（概念）

- 后缀/分号/换行导致脚本被当成可执行或被下载（如 IIS/Nginx+PHP 历史问题）
- `user.ini` / `.htaccess` 被覆盖利用
- 目录遍历、别名配置不当、`alias` 穿越

## 二、反向代理安全

```text
客户端 → Nginx（TLS 终止、路由、限流）→ 后端应用
```

注意：
- `X-Forwarded-For` 可伪造，别直接信
- 隐藏 `Server` 版本
- 管理端点不要暴露公网
- 上传目录禁止执行

## 三、数据库

| 系统 | 默认端口 | 风险 |
|------|----------|------|
| MySQL | 3306 | 弱口令、未授权、注入后扩大 |
| PostgreSQL | 5432 | 弱口令、扩展滥用 |
| SQL Server | 1433 | 弱口令、xp_cmdshell（高危） |
| MongoDB | 27017 | 未授权、勒索 |
| Redis | 6379 | 未授权、写文件、主从复制 |
| Elasticsearch | 9200 | 未授权、数据泄露 |

**最小暴露**：只监听内网、防火墙白名单、强口令、禁用危险命令。

## 四、其他常见中间件

| 组件 | 典型风险 |
|------|----------|
| Jenkins / GitLab | 管理台、CI 密钥、SSRF |
| Nacos / ZooKeeper / Kafka | 未授权、注入配置 |
| Docker API | 未授权 → 容器逃逸/宿主机 |
| Fastjson / Log4j / Struts 等框架 | 组件 RCE（跟版本） |

## 五、服务指纹与版本

- Banner、`Server` 头、报错页、静态资源路径
- `nmap -sV`、Wappalyzer（仅用于授权目标）
- 版本确定后查 CVE/加固公告

## 六、中间件排查清单（防守）

- [ ] 管理端口是否公网可达
- [ ] 默认口令是否改掉
- [ ] 目录列表、调试接口是否关闭
- [ ] 上传目录是否可执行
- [ ] 日志是否集中并告警
- [ ] 组件版本是否在支持周期

## 动手练习

1. 在 DVWA/本地环境画出「浏览器→Nginx→PHP→MySQL」链路
2. 用 `curl -I` 看 `Server` 头并思考信息泄露
3. 列出你电脑/服务器上开放端口对应服务
