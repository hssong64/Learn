# B01-03 · DNS 与常见协议

## 学习目标

- 理解 DNS 解析过程与记录类型
- 了解 SSH、FTP/SFTP、SMB、数据库协议的基本攻击面
- 知道子域名、域传送、DNS 劫持在渗透信息收集中有何用

## 一、DNS 是什么

域名 → IP 的分布式目录系统。浏览器访问 `example.com` 前通常先要解析出 IP（除非已有缓存）。

### 解析流程（简化）

```text
浏览器缓存 → 系统 hosts → 本地 DNS → 根 → 顶级域 → 权威 DNS
→ 得到 A/AAAA 记录 IP → 建立 TCP/TLS 连接
```

## 二、常见 DNS 记录

| 类型 | 含义 | 安全相关 |
|------|------|----------|
| A / AAAA | 域名 → IPv4/IPv6 | 真实 IP、CDN 绕过 |
| CNAME | 别名 | 子域接管（takeover） |
| MX | 邮件服务器 | 邮件伪造、钓鱼仿冒 |
| TXT | 文本（SPF、验证） | SPF/DKIM/DMARC 配置 |
| NS | 权威服务器 | 权威配置错误 |
| PTR | IP → 域名 | 反查 |
| SOA | 起始授权 | 域传送信息 |

**域传送（AXFR）**：若 NS 允许任意主机做 AXFR，可一次拉下所有子域——经典信息收集漏洞。

## 三、DNS 在渗透中的用途

1. **子域名收集**：扩大资产面（注意只测授权范围）
2. **CNAME 接管**：过期云资源 + 未改 CNAME → 可劫持子域
3. **真实 IP**：历史解析、邮件头、证书透明度日志
4. **DNS 隧道**：数据经 DNS 外传（检测侧重点）
5. **缓存投毒 / 劫持**：客户端拿到错误 IP → 中间人

## 四、其他常见协议攻击面

| 协议 | 默认端口 | 典型风险 |
|------|----------|----------|
| SSH | 22 | 弱口令爆破、旧版本漏洞、密钥泄露 |
| FTP | 21 | 明文口令、匿名登录、目录遍历 |
| SFTP/SCP | 22 | 凭据与权限配置 |
| SMB | 445 | 永恒之蓝类、匿名共享、横向移动 |
| RDP | 3306 错误——RDP 是 3389 | 爆破、漏洞、暴露公网 |
| MySQL | 3306 | 弱口令、未授权、注入二次伤害 |
| Redis | 6379 | 未授权、写文件、主从复制 |
| MongoDB | 27017 | 未授权、勒索 |
| Telnet | 23 | 明文，基本淘汰 |
| SMTP | 25/587 | 开放转发、钓鱼 |

> 注：RDP 默认 3389；MySQL 是 3306。记混会让你在报告里出丑。

## 五、服务识别思路

```text
端口开放 → 服务指纹（Banner / nmap -sV）→ 版本漏洞搜索
→ 弱口令/默认口令 → 配置错误（未授权）→ 已知 CVE
```

## 动手练习

1. `nslookup` / `dig` 查看 A、CNAME、MX、TXT
2. 对靶场 `nmap -sV` 看版本指纹
3. 查阅你项目域名的 TXT（SPF）是否存在
