# B01-01 · TCP/IP 与网络分层

## 学习目标

- 掌握分层模型与各层职责
- 理解三次握手/四次挥手、端口、常见协议
- 能读懂抓包里的 SYN/ACK、TTL、端口扫描结果

## 一、分层模型

| 层 | 名称 | 作用 | 例子 |
|----|------|------|------|
| 7 | 应用层 | 业务协议 | HTTP、DNS、SSH、FTP |
| 4 | 传输层 | 端到端、可靠/不可靠 | TCP、UDP |
| 3 | 网络层 | 寻址与路由 | IP、ICMP |
| 2 | 数据链路层 | 帧、MAC | 以太网、ARP |
| 1 | 物理层 | 比特传输 | 网线、光纤 |

**安全视角**：攻击面随层不同——应用层看 Web 漏洞，传输层看端口与中间人，网络层看路由与 ARP 欺骗。

## 二、IP、端口、套接字

- **IP**：逻辑地址（IPv4 如 `192.168.1.10`；私网 10/172.16/192.168）
- **端口**：进程级入口，0–65535；常用：22 SSH、80 HTTP、443 HTTPS、3306 MySQL、6379 Redis、445 SMB
- **Socket**：`IP:端口` + 协议，应用通信端点

**渗透中的含义**：`nmap` 扫的是端口开放/服务指纹；防火墙策略常按 IP/端口/协议放行。

## 三、TCP 要点

### 三次握手

```text
客户端 → SYN → 服务端
客户端 ← SYN+ACK ← 服务端
客户端 → ACK → 服务端
```

### 四次挥手

```text
主动方 → FIN
被动方 → ACK
被动方 → FIN
主动方 → ACK
（随后 TIME_WAIT）
```

### 安全相关现象

| 现象 | 可能含义 |
|------|----------|
| SYN 收到无 ACK | 半开，可能被探测或 SYN Flood |
| 大量短连接同一端口 | 扫描 / 爆破 |
| RST 突增 | 服务拒绝、防火墙拦截、端口未开 |

**UDP**：无连接、不保证可靠；DNS、DHCP、NTP 常见；扫描更依赖协议探测。

## 四、ICMP

- `ping` 用 ICMP Echo
- 有些主机禁 ping 但服务正常（**存活判断不能只看 ping**）
- 可用于隧道（ICMP tunnel）——高阶技巧，先了解

## 五、ARP 与局域网欺骗（概念）

- ARP 把 IP 解析为 MAC
- ARP 欺骗可导致中间人（MITM）
- 防护：静态 ARP、动态 ARP 检测、划分 VLAN

## 六、子网与路由（够用即可）

- 子网掩码 `/24` = 255.255.255.0
- 内网横向时常先扫存活主机再扫端口
- 默认网关是出内网的出口

## 动手练习

1. 在虚拟机里用 `ping`、`tracert`/`traceroute` 观察路径
2. 用 Wireshark 抓一次 TCP 握手，标出 SYN/SYN-ACK/ACK
3. 跑 `nmap -sS -p 22,80,443 <靶机IP>`（仅对你的靶场）

## 自测

1. 为什么 ping 不通但 80 端口可能开着？
2. 三次握手缺少哪一步会造成什么现象？
3. 扫到 3306 开放，下一步应确认什么？
