# F01-01 · 靶场环境搭建

## 学习目标

- 能独立部署 DVWA、SQLi-labs 等基础靶场
- 会用 Docker 加速环境搭建
- 建立可重复、可快照的实验习惯

## 一、通用准备

1. 虚拟机或 Docker
2. 独立网段（Host-Only）
3. 快照 `clean`
4. 记录 IP、账号、端口

## 二、Docker 方式（推荐）

```bash
# 示例：DVWA
docker pull vulnerables/web-dvwa
docker run -d --name dvwa -p 8080:80 vulnerables/web-dvwa

# 示例：SQLi-labs
docker pull acgpiano/sqli-labs
docker run -d --name sqli -p 8081:80 acgpiano/sqli-labs
```

> 镜像名可能随仓库变化，以你实际 `docker search` 为准；**只用官方/常见社区镜像**。

## 三、手动 LAMP 部署 DVWA（理解原理）

```text
1. 安装 Nginx/Apache + PHP + MySQL
2. 下载 DVWA 源码到站点目录
3. 配置数据库连接
4. 访问 /setup.php 初始化
5. 默认账号 admin / password（登录后改掉）
```

常见坑：
- PHP 扩展缺失
- `config` 文件权限
- `allow_url_include` 等 PHP 配置（部分关卡需要）

## 四、SQLi-labs / Upload-labs

| 靶场 | 注意 |
|------|------|
| SQLi-labs | 从 Less-1 开始，别只跑 SQLMap |
| Upload-labs | 配合文件解析环境（Apache/Nginx+PHP） |
| Pikachu | 中文友好，题型全 |

## 五、Metasploitable / 综合主机

- 适合练信息收集、服务漏洞、后渗透入门
- 仍在隔离网段
- 先侦察再动手，模拟真实流程

## 六、浏览器与代理

1. 独立浏览器 Profile 做测试
2. 代理指向 Burp
3. 保存项目文件
4. 实验结束恢复代理

## 七、环境清单模板

| 项 | 值 |
|----|----|
| 靶场名 | DVWA |
| IP:端口 | 192.168.56.10:8080 |
| 账号 | admin |
| 部署方式 | Docker |
| 快照名 | dvwa-clean |
| 备注 | security level 在页面可调 |

## 八、故障排查

```text
访问不通 → 网络模式/IP/防火墙
500 错误 → PHP 错误日志
登录异常 → 初始化/setup
代理后乱 → 证书/拦截开关
```

## 动手练习

1. Docker 部署 DVWA 并登录
2. 把 security level 调到 Low，跑通一个 XSS
3. 回滚快照后再部署一遍，计时
