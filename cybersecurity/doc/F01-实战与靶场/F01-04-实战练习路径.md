# F01-04 · 实战练习路径

## 学习目标

- 制定可持续的练习节奏
- 从专项靶场走到综合主机
- 形成作品集（writeup/报告）

## 一、三级跳

```text
Level 1 专项靶场（DVWA / SQLi-labs / Upload-labs）
    ↓ 熟悉单一漏洞
Level 2 单机综合（VulnHub / HTB Easy）
    ↓ 完整渗透流程
Level 3 业务/多层（THM 路径、企业级实验、SRC 授权）
```

## 二、周计划模板（稳定每周 8–12 小时）

| 日 | 内容 | 时长 |
|----|------|------|
| 二/四 | 理论+笔记（A–E 模块） | 1.5h |
| 三 | 靶场实操 | 2h |
| 六 | 综合目标 / CTF | 3h |
| 日 | 复盘 writeup + 计划 | 1h |

## 三、综合目标练习清单（每台主机）

1. 范围确认（IP、授权）
2. 信息收集（端口、服务、Web）
3. 入口枚举
4. 漏洞验证
5. 获得初始访问
6. 提权（若授权）
7. 写报告式 writeup
8. 快照回滚

## 四、推荐顺序（示例）

| 阶段 | 目标 |
|------|------|
| W1–W2 | DVWA 全模块笔记 |
| W3 | SQLi-labs 前 20 |
| W4 | Upload-labs + 文件类 |
| W5–W6 | HTB/THM Easy × 4 |
| W7–W8 | 有报告要求的完整项目 1 个 |
| W9+ | 按 G01 方向加深 |

## 五、作品集（找工作/SRC 有用）

| 产出 | 说明 |
|------|------|
| writeup | 每台目标一篇 |
| 工具脚本 | GitHub 放学习脚本（脱敏） |
| 报告样本 | 展示专业度 |
| 博客/笔记 | 本仓库 doc/ 持续更新 |

**脱敏**：不放真实客户数据、内网 IP、未公开漏洞细节。

## 六、避免低效勤奋

| 低效 | 高效 |
|------|------|
| 只刷 payload 集 | 每次写原理与修复 |
| 一直 Easy | 适度加难 |
| 只用扫描器 | 手工理解 |
| 看完教程不动手 | 20 分钟内开靶场 |
| 不复盘 | 周复盘固定做 |

## 七、进度检查表

- [ ] 能独立完成一台 Easy 主机并出报告
- [ ] 能讲解 XSS/SQLi/上传/越权 的修复
- [ ] 有 5+ 篇 writeup
- [ ] 有可展示的脚本/工具
- [ ] 明确下一步专精方向
