# F01-03 · CTF Web 入门

## 学习目标

- 了解 CTF Web 题型与解题节奏
- 会从题目描述/源码里找线索
- 把 CTF 当作「短时高强度靶场」来练基本功

## 一、CTF 是什么

Capture The Flag：解题拿 flag（`flag{...}`）。  
Web 方向常考：注入、XSS、SSRF、反序列化、文件包含、逻辑、源码审计、原型链、SSTI 等。

**与渗透测试差异**：CTF 目标明确、有 flag、允许一定「偏方」；渗透更重流程、影响评估与报告。

## 二、题型地图

| 题型 | 关键词 | 入口技能 |
|------|--------|----------|
| 注入类 | SQLi、NoSQLi | C02-03 |
| XSS | 弹窗、打到机器人 | C02-02 |
| 文件 | 上传、包含、穿越 | C02-06 |
| SSRF/XXE | 内网、读文件 | C02-04/07 |
| 反序列化/链 | PHP/Java | C02-07 |
| 前端/JS | 原型污染、混淆 | C01 |
| 逻辑 | 优惠、并发 | C02-08 |
| 信息泄露 | `.git`、源码、备份 | D01-02 |

## 三、解题框架

```text
1. 读题面/附件/域名
2. 收集：响应头、JS、注释、备份、源码
3. 猜测考点（看关键词）
4. 构造最小 PoC
5. 拿到 flag / 写 writeup
```

## 四、信息泄露套路（高频）

```text
.git / .svn / .DS_Store
www.zip / backup.rar
index.php~ / index.php.swp
robots.txt / sitemap
swagger / api docs
源码高亮、调试模式、phpinfo
```

## 五、时间分配（单题 30–60 分钟）

| 阶段 | 分钟 |
|------|------|
| 侦察 | 10 |
| 假设与尝试 | 20 |
| 深入利用 | 20 |
| 放弃/换题 | 及时止损 |

卡住超过 45 分钟看题解思路（学习期），**赛后再完整复现**。

## 六、Writeup 怎么写

1. 题目名与考点
2. 环境
3. 侦察过程（你以为的和实际）
4. 关键 payload
5. 踩坑点
6. 修复/防御视角（加分项）
