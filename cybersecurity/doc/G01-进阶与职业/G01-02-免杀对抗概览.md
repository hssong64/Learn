# G01-02 · 免杀与对抗（概览）

## 学习目标

- 理解攻防对抗的基本模型
- 知道检测面与绕过面的博弈
- 合法使用：仅用于授权红队与防御研究

> **伦理**：免杀技术与恶意软件仅一墙之隔。本节只建立概念与防守认知，不提供可用恶意载荷。

## 一、对抗模型

```text
攻击者：加载 → 执行 → 通信 → 持久化 → 横移
防守方：特征 → 行为 → 启发式 → 沙箱 → 情报
```

## 二、常见检测面

| 层 | 例子 |
|----|------|
| 静态 | 文件哈希、字符串、导入表 |
| 内存 | 行为注入、API 序列 |
| 行为 | 创建进程、改注册表、出网 |
| 流量 | C2 协议、JA3、域名 |
| 端点 EDR | 进程树、命令行、脚本 |
| 网络 | DNS、代理日志、NDR |

## 三、攻击侧概念（名词认识即可）

| 名词 | 含义 |
|------|------|
| 加壳/编码 | 改静态特征 |
| 内存执行 | 少落盘 |
| 间接调用 | 隐藏 API 调用（研究级） |
| 无文件 | 利用系统工具/脚本 |
| C2 框架 | 指挥控制通道 |
| 流量伪装 | 与正常协议相似 |

## 四、防守侧能力（更值得你深耕）

1. **告警规则**：进程树、命令行关键字
2. **沙箱与动态分析**
3. **出网管控**与 DNS 安全
4. **EDR 策略**与攻击面收敛（禁宏、禁脚本解释器滥用）
5. **威胁情报**与 IOC
6. **红蓝对抗**验证检测有效性

## 五、与前端/开发的结合点

- 供应链：npm 包投毒
- 构建脚本与 CI 凭据
- 浏览器扩展安全
- Electron/Node 应用攻击面

## 六、学习路径（正规渠道）

```text
实验域 + 公开防御研究
  → 检测工程（Sigma 规则、日志）
    → 红队课程/认证（需授权场景）
      → 负责任披露与 SRC
```

## 七、红线

| 可以 | 不可以 |
|------|--------|
| 学习检测与公开论文 | 制作传播勒索软件 |
| 实验室对抗 | 对未授权主机免杀投递 |
| 防守规则编写 | 交易恶意样本牟利 |
