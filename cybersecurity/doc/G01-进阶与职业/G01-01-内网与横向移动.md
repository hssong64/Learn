# G01-01 · 内网与横向移动（概览）

## 学习目标

- 理解内网渗透的基本地图
- 知道域、凭据、横移的概念与风险
- 明确仅在授权红队/实验域中练习

> **边界**：内网横移极易越出授权范围。无书面授权禁止对任何真实内网操作。

## 一、内网地图

```text
边界突破（Web/VPN/办公终端）
  → 内网存活探测
    → 端口与服务
      → 凭据/漏洞/配置问题
        → 横移主机
          → 域控 / 数据库 / 文件 / 云控制面
```

## 二、核心概念

| 概念 | 说明 |
|------|------|
| 域 Domain | AD 集中身份与策略 |
| 域控 DC | 域内核心 |
| 凭据 | 密码、哈希、票据、令牌、密钥 |
| 横向移动 | 用合法/非法方式到其他主机 |
| 隧道 | 流量转发绕过边界 |
| 代理 | 出网/入网控制 |

## 三、常见横移路径（概念）

| 路径 | 说明 |
|------|------|
| SSH/RDP/WinRM | 弱口令、复用口令 |
| SMB/自启动 | 历史漏洞、可写共享 |
| 计划任务/服务 | 权限配置 |
| 数据库链接 | 跨库执行 |
| 容器/K8s | 逃逸后到宿主机/集群 |
| 云元数据 | 偷临时密钥（见 SSRF） |

## 四、Windows 域攻击概念（只建图）

- Kerberoasting / AS-REP
- Pass-the-Hash / Pass-the-Ticket
- 委派滥用
- DCSync
- 域信任

这些进阶内容建议在 **刻意搭建的实验域** 学习，配 Microsoft 官方实验或行业红队课程。

## 五、检测与防守（蓝队视角）

| 检测点 | 信号 |
|--------|------|
| 登录日志 | 异常时间/来源/爆破 |
| 新增账号/组 | 权限提升 |
| 计划任务/服务 | 持久化 |
| 出网 | 异常 C2、隧道 |
| 横向登录 | 一账号短时间多主机 |

## 六、隧道与代理（概念）

- 常见：HTTP/DNS/ICMP 隧道
- 风险：数据外传、绕过审计
- 防守：出网白名单、DNS/HTTP 异常检测

## 七、实验建议

1. 自建 Windows Server + 2 台客户端实验域
2. 只在 host-only 网段
3. 学习检测规则与攻击手法对照
4. 清理快照，不留后门
