# G01-03 · 云与容器安全

## 学习目标

- 理解云上共享责任模型
- 认识常见云原生攻击面
- 知道容器/K8s 基础风险与加固方向

## 一、共享责任模型

```text
云商：底层设施、物理、虚拟化
你：配置、镜像、代码、密钥、权限、数据
```

**大部分云上事故是配置错误与权限过大，不是云商「被黑」。**

## 二、云服务攻击面

| 面 | 问题 |
|----|------|
| 元数据服务 | SSRF 偷临时凭据 |
| 存储桶 | 公开读写、枚举 |
| IAM | 权限过大、密钥泄露 |
| 管理 API | 暴露公网、弱认证 |
| 无服务器/云函数 | 事件注入、权限 |
| 日志与密钥 | 明文进代码/日志 |

## 三、容器与镜像

| 风险 | 说明 |
|------|------|
| 镜像投毒 | 公共镜像带后门 |
| 敏感信息进镜像 | `.env`、私钥 |
| 特权容器 | 接近宿主机 |
| 挂载 docker.sock | 逃逸路径 |
| 运行时逃逸 | 内核/配置问题 |
| 网络暴露 | 端口直接开公网 |

加固思路：最小镜像、只读根文件系统、非 root、扫描镜像、签名与来源。

## 四、Kubernetes 概念风险

| 对象 | 风险 |
|------|------|
| ServiceAccount | Token 泄露 |
| RBAC | 权限过大 |
| 暴露 Dashboard/API | 未授权 |
| Secret | 明文、可读过宽 |
| NetworkPolicy | 缺失导致任意横移 |
| 挂载 HostPath | 逃逸 |

## 五、云上测试注意

1. 只在自己的账号/项目
2. 用后关闭权限与资源（省钱与安全）
3. 不要用真实生产密钥
4. 了解云厂商安全基线（CIS Benchmark）

## 六、对 Web 安全的衔接

```text
SSRF → 元数据 → 云凭据 → 控制云资源
文件上传 → 恶意镜像/静态站
CI/CD → 构建密钥泄露 → 供应链
```

## 七、工具与学习
