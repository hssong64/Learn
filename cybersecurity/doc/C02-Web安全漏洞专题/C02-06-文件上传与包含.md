# C02-06 · 文件上传与文件包含

## 学习目标

- 掌握上传漏洞绕过与修复
- 理解文件包含（LFI/RFI）危害
- 知道解析漏洞与 WebShell 的关系（靶场）

## 一、文件上传漏洞

### 危害

| 目标 | 结果 |
|------|------|
| 可执行文件（php/jsp/…） | WebShell、代码执行 |
| 覆盖配置/静态文件 | 篡改、持久化 |
| XSS（SVG/HTML） | 存储型 XSS |
| 路径可控 | 写到关键目录 |
| 超大文件 | DoS |

### 常见绕过（靶场理解原理）

| 维度 | 示例 |
|------|------|
| 后缀黑名单 | `.php5`、`.phtml`、大小写、双写 `phphpp` |
| MIME | 只改 `Content-Type` |
| Content-Type | `image/png` 伪装 |
| 文件头 | GIF89a + 代码 |
| 截断 | 旧解析 `shell.php%00.jpg` |
| 竞争条件 | 先上后杀 |
| `.htaccess` / `user.ini` | 开启解析 |
| 路径穿越文件名 | `../` |

### 修复清单

1. **白名单**扩展名 + 服务端校验
2. 重命名随机文件名，禁用户控制路径
3. 存储与访问分离（OSS、静态服务器），**上传目录不可执行**
4. 限制大小、图片用重新编码而非原样存
5. 权限最小化，杀软/内容检测可辅助
6. 不要仅靠前端 `accept` 或黑名单

## 二、WebShell（靶场概念）

```php
<?php @eval($_POST['cmd']); ?>
```

- 功能：执行命令、文件管理、代理
- 检测：流量特征、文件哈希、行为（异常出网、命令）
- **仅在自己靶场验证**；对未授权系统上传即犯罪

## 三、文件包含

| 类型 | 含义 |
|------|------|
| LFI | 本地文件包含，读 `/etc/passwd`、日志 |
| RFI | 远程包含，拉外部恶意代码（`allow_url_include`） |

典型代码：

```php
include($_GET['page']);  // page=../../../../etc/passwd
```

**日志投毒**：把恶意代码写进 User-Agent，再包含日志文件执行——经典 LFI 链。

### 修复

- 禁止用户输入直接进 `include`
- 白名单页面映射
- 关闭远程包含
- 权限隔离

## 四、路径穿越（常与上传/下载一起）

```text
download?file=../../../etc/passwd
```

修复：规范化路径、白名单目录、拒绝 `..` 与绝对路径、使用安全 API。
