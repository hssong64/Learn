# E01-01 · 信息收集工具

## 学习目标

- 会用 DNS/子域/端口/目录工具
- 理解工具输出如何变成资产表
- 控制速率与范围，避免违规

## 一、DNS 与解析

```bash
dig example.com A
dig example.com AXFR @ns1.example.com
nslookup -type=mx example.com
```

| 工具 | 用途 |
|------|------|
| dig/nslookup | 基础查询 |
| dnsrecon / dnsenum | 枚举 |
| 各类在线 CT / 历史解析 | 被动 |

## 二、子域名

| 思路 | 工具/来源 |
|------|-----------|
| 搜索引擎/CT | crt.sh、被动平台 |
| 字典爆破 | subfinder、oneforall、gobuster + DNS |
| 证书/爬虫/JS | Katana、自写爬虫 |
| 组合平台 | 合规的资产收集平台 |

实践：
1. 先被动
2. 再小字典爆破
3. 去重、解析存活
4. 标注是否在授权范围

## 三、端口与服务

```bash
nmap -sS -p- --min-rate 2000 <ip>          # 全端口初探（授权靶场）
nmap -sV -sC -p 22,80,443 <ip>             # 指纹与默认脚本
nmap -O <ip>                                 # 操作系统猜测
```

| 选项 | 含义 |
|------|------|
| `-sS` | SYN 扫描 |
| `-sV` | 版本 |
| `-sC` | 默认脚本 |
| `--open` | 只看开放 |
| `-iL` | 批量 IP |

**masscan/naabu**：高速发现端口，再用 nmap 识别；注意别扫成 DoS。

## 四、目录与接口

```bash
ffuf -u https://target/FUZZ -w wordlist.txt -mc 200,301,403
dirsearch -u https://target -e php,js,html
```

要点：
- 自定义 wordlist（中文后台、备份文件、`.git`、`actuator`）
- 状态码与长度一起看
- 403 可能是敏感目录

## 五、指纹与技术栈

| 方法 | 工具 |
|------|------|
| 响应头/报错/静态资源 | 手工 + curl |
| 浏览器扩展 | Wappalyzer |
| 指纹库 | whatweb、Wappalyzer DB |
| favicon hash | 在线/自写 |

## 六、输出整理

```text
资产表 → 端口表 → 技术栈 → 入口点（登录/上传/管理）→ 风险假设
```

建议用 Markdown/表格维护，后续报告直接引用。

## 七、纪律

- 写死 scope 变量
- 速率可配置、默认温和
- 只用授权词表与字典
- 日志保存以便证明「只测了范围内」

## 动手练习

1. 对靶场完成：存活 → 端口 → 服务 → 目录
2. 用 ffuf 找到至少 1 个隐藏路径
3. 把结果填进资产表模板
