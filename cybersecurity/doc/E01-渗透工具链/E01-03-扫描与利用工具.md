# E01-03 · 扫描与利用工具

## 学习目标

- 了解主流扫描/利用工具的定位
- 会把工具结果去误报并转成报告
- 明确工具使用边界

## 一、扫描器

| 工具 | 特点 |
|------|------|
| Nessus / OpenVAS | 主机/服务漏洞 |
| Nuclei | 模板化 POC，社区模板多 |
| Burp Scanner | Web 侧（Pro） |
| Nikto | 老牌 Web 简单扫 |
| 各云/WAF 日志侧 | 防守 |

```bash
nuclei -u https://target -t cves/
nuclei -l urls.txt -severity high,critical
```

**模板要注意**：社区模板可能含破坏性；先在靶场验证。

## 二、专项利用工具

| 工具 | 用途 |
|------|------|
| SQLMap | SQL 注入检测利用 |
| xsstrike / dalfox | XSS 辅助 |
| Commix | 命令注入 |
| ysoserial / marshalsec | 反序列化（Java） |
| 系统自带 curl/python | 自定义 PoC |

### SQLMap 例子（靶场）

```bash
sqlmap -u "http://target/page?id=1" --batch --dbs
sqlmap -r request.txt --level=3 --risk=2
```

只读权限够用就别 `--os-shell`；生产禁用高风险选项。

## 三、CMS / 框架工具

- WPScan（WordPress）
- 各类框架专属扫描
- 注意误报与版本识别

## 四、字典与 fuzz

| 类型 | 用途 |
|------|------|
| 目录字典 | 发现隐藏路径 |
| 后台字典 | 中文/拼音/常见 |
| 密码字典 | 仅靶场/授权 |
| 参数字典 | API fuzz |

字典质量 > 工具花哨；优先业务相关词。

## 五、工具结果怎么变成漏洞

```text
工具命中
  → 手工复现
  → 判断是否误报/可利用/影响
  → 记录请求响应
  → 定级与建议
```

**永远不要直接把扫描器 PDF 扔给客户。**

## 六、安全与法律

| 允许 | 禁止 |
|------|------|
| 靶场/授权项目 | 随便扫公网 |
| 控制速率 | 爆破导致业务宕机 |
| 测试后清理 | 保留 WebShell「以后用」 |
| 保密数据 | 把数据上传第三方在线工具 |

## 七、推荐掌握顺序

```text
curl/nmap/ffuf（手工感）
  → Burp（手工改包）
    → SQLMap/Nuclei（专项自动化）
      → 自写脚本（定制化）
```

## 动手练习

1. Nuclei 对靶场跑一轮并人工确认
2. SQLMap 对 SQLi-labs 某一关跑通并读懂输出
3. 写「工具误报处理」三条经验

## 自测

3. 你更信任字典大还是目标理解深？为什么？
