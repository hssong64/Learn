# A00 · 网络安全与渗透测试 学习大纲

> 面向对象：2 年前端开发，从 0 到 1 搭建网络安全 / 网络渗透知识体系。
> 目标：建立合法合规的安全认知 → 打牢网络与系统基础 → 吃透 Web 安全（发挥前端优势）→ 掌握渗透测试方法与工具 → 靶场实战 → 明确进阶方向。

---

## 一、学习目标

| 阶段 | 目标 | 完成标志 |
|------|------|----------|
| 入门（第 1–2 周） | 理解安全行业、法律边界、核心概念 | 能说清授权测试与违法渗透的区别 |
| 基础（第 3–5 周） | 网络协议、Linux/Windows、常见服务 | 能独立抓包分析 HTTP/DNS，会用 Linux 做基础排查 |
| Web 安全（第 6–10 周） | OWASP 主流漏洞原理与利用 | 能在靶场独立完成 XSS / SQLi / 文件上传等 |
| 方法与工具（第 11–13 周） | 渗透流程 + 工具链 | 能按完整流程对靶场目标出报告 |
| 实战与进阶（第 14 周起） | CTF / 综合靶场 / 方向选择 | 完成至少 1 个综合靶场并输出报告 |

## 四、给前端同学的路径建议

1. **先发挥优势**：HTML/JS/HTTP/浏览器安全模型你已经会一半，C 模块可加速。
2. **不要跳过 B**：看不懂流量和系统，渗透只是背 payload。
3. **法律优先于技术**：无授权测试任何真实系统都是违法的；只练靶场与 SRC。
4. **输出倒逼输入**：每学完一节，在 `memory/` 记操作，用「能教给别人」检验是否真懂。
5. **工具是手段**：先理解漏洞原理，再用工具；避免成为「点按钮」脚本小子。
