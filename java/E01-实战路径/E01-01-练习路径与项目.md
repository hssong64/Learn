# E01-01 · Java 练习路径与项目

## 学习目标

- 有可执行的刷题与项目路径
- 能写出可展示的 README 与代码规范
- 知道面试常考点

## 一、练习三级跳

```text
Level 1 语法与 OOP 小题（命令行）
Level 2 集合/IO/并发练习
Level 3 Spring Boot 项目 + 测试
```

## 二、刷题清单

| 主题 | 题目 |
|------|------|
| 数组字符串 | 两数之和、反转链表、括号匹配 |
| 集合 | LRU、词频、TopK |
| 并发 | 生产者消费者、顺序打印 |
| 设计 | 线程池封装、缓存 |

## 三、推荐综合项目

**任务管理系统（Task Manager）**

| 模块 | 能力 |
|------|------|
| 用户 | 注册登录（JWT）、角色 |
| 任务 | CRUD、状态流转、分页 |
| 工程 | 分层、校验、异常、日志 |
| 测试 | Service 单测、接口测试 |
| 扩展 | Redis 缓存、定时任务、简单监控 |

## 四、项目结构建议

```text
task-manager/
├── controller/
├── service/
├── repository/
├── model/ (entity/dto/vo)
├── config/
├── exception/
└── util/
```

## 五、代码质量

- 单一职责
- 小方法、好命名
- 关键路径有测试
- 敏感信息不入库
- 版本控制 + 有意义的 commit

## 六、面试清单（Java 后端）

1. 集合原理与选型
2. equals/hashCode
3. 线程池参数与拒绝策略
4. synchronized 与 Lock
5. JVM 内存与 GC
6. Spring IoC/AOP
7. 事务失效场景
8. SQL 注入与 PreparedStatement
9. 缓存三大问题
10. 排查线上 CPU/内存问题思路

## 动手练习

1. 两周完成 Task Manager MVP
2. 写 README：架构、接口列表、启动方式
3. 录一版 5 分钟项目讲解

## 自测

1. 项目里如何体现分层？
2. 哪些地方需要日志？
3. 如何向面试官讲清一个并发 bug？
