# A00 · Java 学习大纲

> 面向对象：有前端/其他语言基础，想系统掌握 Java 与企业后端。
> 目标：能读懂并写出规范 Java → 掌握集合/并发/JVM 基础 → 会 Maven/Spring 入门 → 有可展示的练习项目。

---

## 一、学习目标

| 阶段 | 目标 | 完成标志 |
|------|------|----------|
| 语法（1–2 周） | 语法、类型、控制流、数组 | 能独立写命令行小工具 |
| OOP（1–2 周） | 类、继承、接口、多态 | 能设计 3 个小项目类图 |
| 核心库（2 周） | 集合、异常、IO、泛型 | 能解释 ArrayList/HashMap 原理 |
| 并发与 JVM（2 周） | 线程、锁、JMM、GC | 能排查简单线程安全问题 |
| 工程与框架（2 周） | Maven、Spring IoC/AOP、Web | 能跑通简单 Spring Boot API |
| 实战（持续） | 项目 + 刷题 | 1 个可运行的后端小项目 |

## 四、与前端背景的衔接

| 你已熟悉 | Java 对应 |
|----------|-----------|
| TypeScript 接口/类型 | 接口、泛型、封装 |
| Node 模块/包 | Maven 依赖、包名 |
| 异步 Promise | 线程、Future、CompletableFuture |
| JSON | Jackson / Gson |
| Express 路由 | Spring MVC / WebFlux |
| npm scripts | Maven 坐标与插件 |

**要补的思维**：静态类型编译、JVM 内存、显式并发、企业分层（Controller/Service/Mapper）。
