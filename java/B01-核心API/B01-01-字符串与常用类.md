# B01-01 · 字符串与常用类

## 学习目标

- 吃透 String 不可变与常用 API
- 会用 StringBuilder/包装类/工具类
- 避免常见性能与空指针问题

## 一、String 不可变

```java
String s = "hi";
s.concat("!");   // 新对象，s 仍是 "hi"
s = s.concat("!");
```

好处：常量池、线程安全、可作 map 键。  
频繁拼接用 `StringBuilder`。

## 二、常用 API

```java
s.length();
s.charAt(0);
s.substring(1, 3);
s.split(",");
s.trim();
s.equals(other);
s.isBlank();
String.format("%s-%d", name, id);
```

比较用 `equals`，`isBlank` 区分空白串。

## 三、StringBuilder

```java
StringBuilder sb = new StringBuilder();
sb.append("a").append("b");
String out = sb.toString();
```

单线程优先 `StringBuilder`；多线程同步用 `StringBuffer`。

## 四、包装类

```java
Integer n = Integer.parseInt("12");
int m = n;
Integer cache = Integer.valueOf(127);
```

注意缓存范围与 NPE。

## 五、工具类速查

| 类 | 用途 |
|----|------|
| `java.util.Objects` | `requireNonNull`、`equals`、`hash` |
| `java.util.Arrays` | 排序、填充、比较 |
| `java.math.BigDecimal` | 精确小数 |
| `java.time.*` | 日期时间（优先于 Date） |

```java
LocalDate d = LocalDate.now();
LocalDateTime t = LocalDateTime.parse("2026-09-30T10:00:00");
```
