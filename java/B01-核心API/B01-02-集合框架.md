# B01-02 · 集合框架

## 学习目标

- 掌握 List/Set/Map 核心实现
- 理解时间复杂度与选型
- 会遍历、排序、去重

## 一、Collection 体系

```text
Collection
 ├─ List：有序可重复
 │   ├─ ArrayList：数组，随机访问快
 │   └─ LinkedList：链表，插入删除快
 ├─ Set：不重复
 │   ├─ HashSet：哈希
 │   └─ TreeSet：排序
 └─ Queue/Deque：队列

Map：键值对
 ├─ HashMap
 ├─ TreeMap
 └─ LinkedHashMap
```

## 二、List

```java
List<String> list = new ArrayList<>();
list.add("a");
list.add(0, "b");
list.get(0);
list.remove("a");
for (String s : list) { }
```

## 三、Map

```java
Map<String, Integer> map = new HashMap<>();
map.put("a", 1);
map.getOrDefault("b", 0);
map.merge("a", 1, Integer::sum);

for (Map.Entry<String, Integer> e : map.entrySet()) {
    System.out.println(e.getKey() + ":" + e.getValue());
}
```

## 四、选型表

| 场景 | 选择 |
|------|------|
| 按下标随机访问 | ArrayList |
| 频繁头部插入 | LinkedList / Deque |
| 去重 | HashSet |
| 需要排序 | TreeSet / TreeMap |
| 键值缓存 | HashMap |
| 保持插入序 | LinkedHashMap |

## 五、注意点

- HashMap 允许一个 `null` 键（实现相关，别依赖）
- 遍历中删除用 `Iterator.remove()` 或 `removeIf`
- 覆写 equals/hashCode 才能正确作键
- 多线程：`ConcurrentHashMap`
