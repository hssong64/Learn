# A02-03 · final、包与常用对象方法

## 学习目标

- 掌握 final、static、包组织
- 覆写 `equals`/`hashCode`/`toString`
- 了解内部类与枚举

## 一、final

| 场景 | 效果 |
|------|------|
| 变量 | 不能改（基本值/引用不能换） |
| 方法 | 不能重写 |
| 类 | 不能继承 |

```java
final int MAX = 10;
```

## 二、包与导入

```java
package com.example.demo;
import java.util.List;
import java.util.*;
```

- 包名组织类、控制访问
- 静态导入：`import static java.lang.Math.PI;`

## 三、Object 方法

```java
public class User {
    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (!(o instanceof User user)) return false;
        return Objects.equals(name, user.name);
    }
    @Override
    public int hashCode() {
        return Objects.hash(name);
    }
    @Override
    public String toString() {
        return "User{" + name + "}";
    }
}
```

**规则**：`equals` 为 true 时 `hashCode` 必须相同；集合键务必一起覆写。

## 四、枚举

```java
enum Status {
    OPEN, CLOSED, PENDING;
}
```

- 类型安全
- 可带字段、方法
- 比魔法数字清晰

## 五、内部类

| 类型 | 说明 |
|------|------|
| 成员内部类 | 依附外部实例 |
| 静态嵌套类 | 不依赖外部实例 |
| 局部/匿名 | 一次性实现 |

优先静态嵌套类，避免泄漏。
