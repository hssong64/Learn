# A02-02 · 继承、多态与接口

## 学习目标

- 掌握继承与方法重写
- 理解多态与抽象类
- 会用接口设计可扩展结构

## 一、继承

```java
class Animal {
    void speak() { System.out.println("..."); }
}
class Dog extends Animal {
    @Override
    void speak() { System.out.println("wang"); }
}
```

- Java 单继承，多层 `extends`
- `super()` 调父类构造
- `Object` 是根类

## 二、方法重写（Override）

- 方法签名相同
- 访问权限不能更严
- 返回类型协变
- `@Override` 帮助编译器检查

**重载（Overload）**：同类同名不同参数，与继承无关。

## 三、多态

```java
Animal a = new Dog();
a.speak(); // wang
```

- 编译看父类，运行看子类
- 依赖继承/接口 + 重写
- 好处：可替换、可扩展

## 四、抽象类

```java
abstract class Shape {
    abstract double area();
}
class Circle extends Shape {
    double area() { return Math.PI * r * r; }
}
```

- 可含抽象方法与具体方法
- 不能直接 `new`

## 五、接口

```java
interface Payable {
    boolean pay(int amount);
}
interface Refundable {
    void refund();
}
class Order implements Payable, Refundable {
    // ...
}
```

- 多实现
- Java 8+ 默认方法、静态方法
- 常量 `public static final`

## 六、抽象类 vs 接口

| | 抽象类 | 接口 |
|--|--------|------|
| 继承 | 单继承 | 多实现 |
| 成员 | 字段、构造器 | 常量、默认/抽象方法 |
| 用途 | is-a 共性 | can-do 能力 |
| 设计 | 抽象属性 | 契约/行为 |
