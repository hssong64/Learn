# A02-01 · 类与对象

## 学习目标

- 理解类、对象、方法、构造器
- 掌握封装与访问修饰符
- 会写规范的实体类

## 一、类的组成

```java
public class User {
    private String name;
    private int age;

    public User(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
}
```

成员：字段、构造器、方法、（嵌套类型）

## 二、对象生命周期

```java
User u = new User("tom", 18);
```

- `new` 在堆上分配并调用构造器
- 变量 `u` 在栈上保存引用
- 没有显式 `delete`，由 GC 回收

## 三、方法

```java
public int add(int a, int b) {
    return a + b;
}
```

- 重载：同名不同参数
- 传参：基本类型传值，引用类型传引用（对象内容可改）
- `return` 结束方法

## 四、封装

| 修饰符 | 类内 | 同包 | 子类 | 其他 |
|--------|------|------|------|------|
| private | √ | | | |
| default | √ | √ | | |
| protected | √ | √ | √ | |
| public | √ | √ | √ | √ |

原则：字段 `private`，对外 `getter/setter` 或行为方法。

## 五、构造器与 this

- 与类同名，无返回值
- 可重载
- `this` 指当前对象；`this(...)` 调其他构造器

## 六、静态成员

```java
class Counter {
    static int count = 0;
    static void inc() { count++; }
}
```

- 属于类，不属对象
- 实例方法可访问静态成员，反向不行（非静态上下文）
