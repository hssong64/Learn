# C01-02 · 并发工具与线程池

## 学习目标

- 掌握 Lock、并发集合、线程池参数
- 会避免 OOM 与任务堆积
- 理解 Future/CompletableFuture

## 一、Lock

```java
Lock lock = new ReentrantLock();
lock.lock();
try {
    // ...
} finally {
    lock.unlock();
}
```

可中断、可超时、可公平；与 `synchronized` 互斥即可。

## 二、并发集合

| 类 | 用途 |
|----|------|
| ConcurrentHashMap | 并发 map |
| CopyOnWriteArrayList | 读多写少 |
| BlockingQueue | 生产者消费者 |
| ConcurrentLinkedQueue | 无锁队列 |

## 三、线程池参数

```java
new ThreadPoolExecutor(
    5, 10, 60, TimeUnit.SECONDS,
    new ArrayBlockingQueue<>(100),
    new ThreadPoolExecutor.CallerRunsPolicy());
```

| 参数 | 含义 |
|------|------|
| core | 核心线程 |
| max | 最大线程 |
| keepAlive | 非核心空闲回收 |
| queue | 任务队列 |
| policy | 拒绝策略 |

**阿里规范**：不用 `Executors.newFixedThreadPool` 默认无界队列，显式创建。

## 四、Future / CompletableFuture

```java
CompletableFuture<String> f = CompletableFuture.supplyAsync(() -> fetch());
f.thenApply(String::toUpperCase)
 .thenAccept(System.out::println);
```

组合异步任务，避免阻塞主线程。

## 五、实践建议

1. 线程池按业务隔离
2. 任务超时与监控
3. 避免 ThreadLocal 泄漏（用后 remove）
4. 读写锁、信号量按场景用
