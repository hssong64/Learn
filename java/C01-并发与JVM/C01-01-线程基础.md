# C01-01 · 线程基础与 synchronized

## 学习目标

- 会创建线程、理解生命周期
- 掌握 synchronized 与可见性
- 能识别并修复简单线程安全问题

## 一、创建线程

```java
Thread t = new Thread(() -> System.out.println("run"));
t.start();

ExecutorService pool = Executors.newFixedThreadPool(4);
pool.submit(() -> work());
pool.shutdown();
```

生产优先线程池，避免裸 `new Thread`。

## 二、生命周期

```text
NEW → RUNNABLE → (WAITING/TIMED_WAITING/BLOCKED) → TERMINATED
```

## 三、synchronized

```java
public synchronized void inc() { count++; }
// 或
synchronized (lock) {
    count++;
}
```

- 保证原子性 + 可见性
- 同一把锁才互斥
- 过度使用性能差、易死锁

## 四、volatile

- 保证可见性与有序性
- **不保证复合操作原子性**
- 适用状态标志

## 五、原子类

```java
AtomicInteger count = new AtomicInteger();
count.incrementAndGet();
```

高并发计数优先原子类或 `LongAdder`。

## 六、常见问题

| 问题 | 表现 |
|------|------|
| 竞态 | 丢更新 |
| 死锁 | 双方持锁等待 |
| 活锁/饥饿 | 长期无法进展 |

锁顺序一致、锁粒度合适、避免在锁里做慢 IO。
