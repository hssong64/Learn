# C01-03 · JVM 基础

## 学习目标

- 理解内存区域与对象生命周期
- 了解 GC 常见算法与日志
- 能排查 OOM/NPE 类问题

## 一、运行时数据区（简化）

```text
线程私有：栈（局部变量、操作数）、程序计数器、本地方法栈
共享：堆（对象）、元空间/方法区（类元数据）
```

## 二、对象分配

1. 逃逸分析后可能栈上分配/标量替换
2. 多数在新生代 Eden
3. GC 后存活进 Survivor，老年代
4. 大对象直接老年代

## 三、GC 概念

| 概念 | 说明 |
|------|------|
| 可达性 | 从 GC Root 出发能否到达 |
| 分代 | 新生代/老年代策略 |
| STW | 停顿应用 |
| 并发/并行 | 吞吐与延迟权衡 |

常见收集器（名字认识即可）：Serial、Parallel、G1、ZGC。

## 四、常见问题

| 现象 | 思路 |
|------|------|
| `OutOfMemoryError: Java heap space` | 内存泄漏、加载过多、调参 |
| `StackOverflowError` | 递归过深 |
| 频繁 Full GC | 旧对象多、内存泄漏、GC 配置 |

```bash
java -Xms512m -Xmx512m -XX:+HeapDumpOnOutOfMemoryError
```

## 五、工具

- `jps`、`jstat`、`jmap`、`jstack`
- VisualVM、MAT、Arthas
- GC 日志：`-Xlog:gc*`

## 六、内存泄漏排查思路

1. 确认现象与时间点
2. 堆 dump
3. 找占内存大对象与引用链
4. 常见源：静态集合、ThreadLocal、监听器未注销、连接未关

## 动手练习

1. 画一张 JVM 内存图
2. 制造一次堆 OOM 并抓 dump（小实验）
3. 写笔记：栈溢出 vs 堆溢出
