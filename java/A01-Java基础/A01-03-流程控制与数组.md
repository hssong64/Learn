# A01-03 · 流程控制与数组

## 学习目标

- 熟练分支、循环、跳转
- 掌握一维/二维数组与增强 for
- 能做基础算法题

## 一、分支

```java
if (score >= 90) {
    // ...
} else if (score >= 60) {
    // ...
} else {
    // ...
}

switch (level) {
    case 1 -> System.out.println("L1");
    case 2, 3 -> System.out.println("L2/3");
    default -> System.out.println("?");
}
```

Java 14+ 支持 switch 表达式与箭头语法，减少 fall-through 问题。

## 二、循环

```java
for (int i = 0; i < 10; i++) { }

while (cond) { }

do { } while (cond);

for (String item : list) { }
```

跳转：
- `break` 跳出本层循环
- `continue` 进入下一轮
- 标签循环：`outer: for (...) { continue outer; }`

## 三、数组

```java
int[] a = new int[5];
int[] b = {1, 2, 3};
int[][] m = new int[2][3];

System.out.println(a.length);
```

- 长度固定
- 下标从 0 开始
- 越界抛 `ArrayIndexOutOfBoundsException`
- 对象数组元素默认 `null`

## 四、常用操作

```java
import java.util.Arrays;
Arrays.sort(a);
int[] copy = Arrays.copyOf(a, a.length);
System.out.println(Arrays.toString(a));
```

## 五、小算法清单（建议刷）

| 题 | 练什么 |
|----|--------|
| 求最大值/平均 | 循环边界 |
| 冒泡/选择排序 | 双重循环 |
| 二分查找 | 边界与中间值 |
| 矩阵转置 | 二维数组 |
| 猜数字游戏 | 循环 + 随机 + 输入 |
