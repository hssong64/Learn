# A01-01 · 环境与语法入门

## 学习目标

- 搭好 JDK + IDEA/Maven 环境
- 掌握程序结构、入口、编译运行
- 写出第一个规范工程目录

## 一、环境准备

| 项 | 建议 |
|----|------|
| JDK | 17 或 21（LTS） |
| IDE | IntelliJ IDEA |
| 构建 | Maven 3.9+ |
| 版本管理 | `sdkman` / 安装包均可 |

```bash
java -version
javac -version
```

## 二、第一个程序

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java");
    }
}
```

```bash
javac Hello.java
java Hello
```

- 类名 = 文件名（public）
- 入口固定：`public static void main(String[] args)`
- 语句以 `;` 结束

## 三、项目目录（Maven 标准）

```text
my-app/
├── pom.xml
└── src/
    ├── main/java/com/example/App.java
    └── test/java/com/example/AppTest.java
```

包名习惯：反写域名 `com.example.demo`。

## 四、注释与文档

```java
// 单行
/* 多行 */
/**
 * Javadoc
 * @param args 参数
 */
```

## 五、编译与字节码

```text
.java → javac → .class（字节码）→ JVM 执行
```

跨平台因为 JVM，而不是源码直接跑。

## 六、代码风格

- 类名大驼峰，方法/变量小驼峰
- 常量全大写下划线：`MAX_SIZE`
- 一个文件一个主类
- 复杂逻辑写清命名，少写魔法数
