# A01-02 · 类型系统与运算符

## 学习目标

- 掌握 8 种基本类型与引用类型
- 理解装箱、转换、运算符优先级
- 能避免常见的精度与空指针陷阱

## 一、基本类型

| 类型 | 位数 | 包装类 | 默认值 |
|------|------|--------|--------|
| byte | 8 | Byte | 0 |
| short | 16 | Short | 0 |
| int | 32 | Integer | 0 |
| long | 64 | Long | 0L |
| float | 32 | Float | 0.0f |
| double | 64 | Double | 0.0d |
| char | 16 | Character | '\u0000' |
| boolean | - | Boolean | false |

```java
int age = 18;
double price = 9.99;
char c = 'A';
boolean ok = true;
long big = 1_000_000_000L;
```

## 二、引用类型

- 类、接口、数组、枚举、记录（record）
- 变量存的是引用，对象在堆上
- 可 `null`（基本类型不能）

```java
String name = "tom";
int[] nums = new int[3];
```

## 三、类型转换

```java
int i = 10;
double d = i;          // 自动提升
int x = (int) 9.8;     // 强转，截断 → 9
```

注意：
- 浮点精度：`0.1+0.2 != 0.3`，钱用 `BigDecimal`
- 溢出：`int` 乘法可能溢出，大数据用 `long`
- 装箱缓存：`Integer` 在 -128~127 有缓存，`==` 可能为 true，比较用 `equals` 或 `intValue`

## 四、运算符

| 类 | 例子 |
|----|------|
| 算术 | `+ - * / %` |
| 比较 | `== != > <` |
| 逻辑 | `&& \|\| !` |
| 位 | `& \| ^ ~ << >>` |
| 赋值 | `+=` 等 |
| 三元 | `cond ? a : b` |

`&&` 短路；`&` 对 boolean 不短路，对整型是位运算。

## 五、字符串（入门）

```java
String s = "abc";
String t = new String("abc"); // 堆上另一对象
int n = s.length();
boolean eq = s.equals(t);     // 用 equals 比内容
```

拼接频繁用 `StringBuilder`。

## 六、常见坑

1. `==` 比引用，内容比较用 `equals`
2. `int / int` 是整除
3. `char` 加减变成数字运算
4. 自动装箱后 `null` 拆箱会 NPE
