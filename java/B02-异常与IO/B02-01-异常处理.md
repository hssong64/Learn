# B02-01 · 异常处理

## 学习目标

- 分清受检/非受检异常
- 会写规范 try-catch-finally 与 try-with-resources
- 设计可维护的错误码/异常体系

## 一、体系

```text
Throwable
 ├─ Error（严重，程序难处理）如 OOM
 └─ Exception
     ├─ 受检：IOException、SQLException…必须处理
     └─ 非受检 RuntimeException：NPE、IllegalArgument…
```

## 二、语法

```java
try {
    // 可能出错
} catch (IOException e) {
    throw new BusinessException("读取失败", e);
} finally {
    // 通常释放资源
}
```

```java
try (var in = Files.newInputStream(path)) {
    // 自动 close
}
```

## 三、原则

1. 不要 `catch (Exception e) {}` 吞异常
2. 捕获具体类型
3. 保留 cause：`new Xxx(e)`
4. 不要用异常做流程控制
5. 对外错误信息不泄露堆栈/SQL

## 四、自定义异常

```java
public class BizException extends RuntimeException {
    private final String code;
    public BizException(String code, String message) {
        super(message);
        this.code = code;
    }
}
```

- 业务用非受检异常 + 全局处理器
- 受检异常用于可恢复且调用方必须处理的场景

## 五、日志与排查

```java
log.error("create user failed, id={}", id, e);
```

- 打关键上下文
- 保留异常链
- 统一错误码文档
