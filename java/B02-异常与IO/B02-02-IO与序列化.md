# B02-02 · IO 与 NIO 入门

## 学习目标

- 掌握字节流/字符流与常用文件 API
- 会用缓冲与 try-with-resources
- 了解 NIO 与序列化概念

## 一、流分类

| 类型 | 例子 |
|------|------|
| 字节流 | InputStream / OutputStream |
| 字符流 | Reader / Writer |
| 缓冲 | BufferedInputStream 等 |
| 对象 | ObjectInputStream（序列化） |

文本优先字符流并指定 UTF-8。

## 二、文件常用

```java
Path path = Path.of("data.txt");
Files.writeString(path, "hello", StandardCharsets.UTF_8);
String s = Files.readString(path);
List<String> lines = Files.readAllLines(path);
Files.copy(src, dest);
Files.createDirectories(Path.of("logs"));
```

## 三、传统拷贝

```java
try (var in = new FileInputStream(src);
     var out = new FileOutputStream(dst);
     var bin = new BufferedInputStream(in);
     var bout = new BufferedOutputStream(out)) {
    bin.transferTo(bout);
}
```

## 四、NIO 概念

- Channel、Buffer、Selector
- 大文件、高并发连接更高效
- 业务 CRUD 先用 `java.nio.file.Files` 即可

## 五、序列化注意

- `Serializable` 标记接口
- 存在安全与兼容风险，跨系统优先 JSON
- 不要把序列化当长期存储格式（版本脆弱）

## 六、字符编码

- 默认编码随系统变，显式 `StandardCharsets.UTF_8`
- 中文乱码九成是编码不一致
