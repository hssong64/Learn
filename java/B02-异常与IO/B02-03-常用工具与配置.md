# B02-03 · 常用工具与配置

## 学习目标

- 会用 `Objects`、`Collections`、`Comparator`
- 会读配置文件与属性
- 了解日志门面 SLF4J 思想

## 一、Objects / Collections

```java
Objects.requireNonNull(name, "name");
Collections.sort(list);
Collections.unmodifiableList(list);
Collections.emptyList();
```

## 二、Comparator 链

```java
users.sort(Comparator
    .comparing(User::getDept)
    .thenComparing(User::getAge, Comparator.reverseOrder()));
```

## 三、配置文件

```java
Properties props = new Properties();
try (var in = Files.newInputStream(Path.of("application.properties"))) {
    props.load(in);
}
String url = props.getProperty("db.url");
```

Spring 项目用 `@Value` / `@ConfigurationProperties`。

## 四、日志门面

```java
private static final Logger log = LoggerFactory.getLogger(UserService.class);
log.info("user saved, id={}", id);
```

- 不要 `System.out` 上生产
- 参数化 `{}`，避免字符串拼接
- 级别：trace/debug/info/warn/error

## 五、时间与格式化

```java
DateTimeFormatter fmt = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
String now = LocalDateTime.now().format(fmt);
```
