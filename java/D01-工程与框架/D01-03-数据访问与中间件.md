# D01-03 · 数据访问与常用中间件

## 学习目标

- 会 JDBC/MyBatis/JPA 入门
- 认识 Redis、消息队列在架构中的位置
- 能写基本的持久层代码

## 一、JDBC 基础

```java
try (Connection c = dataSource.getConnection();
     PreparedStatement ps = c.prepareStatement("select * from user where id=?")) {
    ps.setLong(1, id);
    try (ResultSet rs = ps.executeQuery()) { }
}
```

**必须 PreparedStatement**，防 SQL 注入。

## 二、MyBatis 概念

```java
public interface UserMapper {
    @Select("select * from user where id = #{id}")
    User findById(@Param("id") Long id);
}
```

或 XML 映射。适合手写 SQL 可控场景。

## 三、JPA / Spring Data JPA

- 实体映射，方法名派生查询
- 适合快速 CRUD
- 复杂 SQL 仍可 `@Query`

## 四、事务

```java
@Transactional
public void transfer(Long from, Long to, BigDecimal amount) { }
```

- 传播、隔离、回滚规则
- 异常需触发回滚（RuntimeException 默认）
- 长事务勿套远程调用

## 五、Redis（概念）

| 用途 | 说明 |
|------|------|
| 缓存 | 热点数据 |
| 分布式锁 | SETNX 等 |
| 计数/限流 | 原子命令 |
| 会话 | 存 token |

注意：缓存一致性、穿透/击穿/雪崩。

## 六、消息队列（概念）

- 削峰填谷、异步、解耦
- 消费幂等、重试与死信
- 常见：Kafka、RocketMQ、RabbitMQ
