# A01-01 · 类型、作用域与对象

## 学习目标

- 吃透类型转换与相等
- 理解作用域、闭包、this
- 理解原型与继承

## 一、类型

```javascript
typeof null; // "object"
Array.isArray([]); // true
Number("1px"); // NaN
```

- 原始类型 vs 引用类型
- `==` 宽松比较坑多，优先 `===`
- `Object.is`、`Number.isNaN` 更精确

## 二、作用域与闭包

```javascript
function counter() {
  let n = 0;
  return () => ++n;
}
const inc = counter();
```

闭包 = 函数记住词法环境。

## 三、this

```javascript
const obj = {
  name: "a",
  hi() { return this.name; },
};
const hi = obj.hi; // this 丢失
```

箭头函数没有自己的 this；方法传递注意绑定。

## 四、原型

```javascript
function User(name) { this.name = name; }
User.prototype.hi = function () { return this.name; };

class User2 {
  constructor(name) { this.name = name; }
  hi() { return this.name; }
}
```

`class` 是原型语法糖；继承用 `extends`。

## 五、常见坑

- `const` 对象内容可变
- 浮点精度
- `forEach` 不能 await 串行
- 可选链 `?.` 与空值合并 `??`
