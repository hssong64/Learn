2. 代码分割与懒加载

4. 缓存与预加载
5. 避免布局抖动

```javascript
// 防抖
function debounce(fn, wait = 200) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), wait);
  };
}
```
