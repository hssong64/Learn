---

## 二、三种布局怎么选

```text
文档流/块级     → 普通长文页
Flex            → 一维导航、工具栏、卡片行
Grid            → 页面级二维布局、复杂卡片
```

---

## 三、可维护性原则

1. 少用 `!important`
2. 变量统一颜色/间距
3. BEM 或 CSS Modules 控制命名
4. 移动优先
5. 不用固定像素扛所有设备
