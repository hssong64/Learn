# B01-01 · 变量、容器查询与现代 CSS

## 学习目标

- 会用 CSS 变量做主题
- 了解容器查询、`clamp`、`inset`
- 建立组件化样式习惯

## 一、变量与主题

```css
:root {
  --bg: #0b1020;
  --text: #e8eefc;
  --accent: #4f8cff;
}
body {
  background: var(--bg);
  color: var(--text);
}
[data-theme="light"] {
  --bg: #ffffff;
  --text: #111;
}
```

## 二、现代取值

```css
.hero h1 {
  font-size: clamp(1.5rem, 2vw + 1rem, 3rem);
}
.card {
  inset: 0; /* top/right/bottom/left */
}
```

## 三、容器查询（组件自适应）

```css
.card-wrap {
  container-type: inline-size;
}
@container (min-width: 360px) {
  .card { display: flex; }
}
```

组件级响应比全局断点更可复用。

## 四、层叠与现代特性

```css
.panel {
  background: rgb(0 0 0 / 0.4);
  backdrop-filter: blur(8px);
  transition: transform .2s ease;
}
.panel:where(:hover, :focus-within) { transform: translateY(-2px); }
```

`@layer` 可管理第三方与基础样式优先级。

## 五、架构建议

| 层 | 内容 |
|----|------|
| tokens | 颜色、间距、圆角变量 |
| base | reset、排版 |
| components | 组件样式 |
| utilities | 少量工具类 |
| pages | 页面特例 |
