# A02-01 · 响应式与断点

## 学习目标

- 移动优先写响应式
- 会选断点而非写死设备型号
- 处理图片、导航、表格的响应式

## 一、移动优先

```css
.wrap { padding: 12px; grid-template-columns: 1fr; }
@media (min-width: 768px) {
  .wrap { grid-template-columns: 1fr 1fr; padding: 24px; }
}
```

先小屏默认，再增强。

## 二、断点策略

| 断点 | 场景 |
|------|------|
| ~640px | 手机→大手机/小平板 |
| ~768–960px | 平板 |
| ~1200px | 桌面 |
| 大屏 | 限制最大阅读宽度 |

以**内容破版点**为准，不为某机型写专门样式。

## 三、响应式技巧

```css
img { max-width: 100%; height: auto; }
.container { width: min(100% - 24px, 1120px); margin-inline: auto; }
.overflow { overflow-x: auto; }
```

## 四、导航模式

- 桌面：水平菜单
- 小屏：汉堡 + 抽屉（注意焦点管理）
- 或优先关键操作，次要进「更多」

## 动手练习

1. 把固定宽度页改成响应式
2. 表格小屏横向滚动
3. 用 DevTools 模拟测 3 个宽度
