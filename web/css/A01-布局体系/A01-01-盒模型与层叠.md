# A01-01 · 选择器、盒模型与层叠

## 学习目标

- 吃透盒模型与 `box-sizing`
- 理解层叠、优先级、继承
- 写出可预测的选择器

## 一、盒模型

```css
* { box-sizing: border-box; }
.box {
  width: 200px;
  padding: 16px;
  border: 1px solid #ddd;
}
```

`border-box` 时 width 包含 padding/border。

## 二、优先级

```text
行内 > id > class/属性/伪类 > 元素/伪元素
```

技巧：
- 优先降低选择器复杂度
- 组件内用单一 class
- `!important` 仅救命

## 三、常用选择器

```css
.card {}
.card > .title {}
.card:hover {}
.card[data-state="active"] {}
.card + .card {}
.input:focus-visible {}
```

## 四、位置与层叠上下文

```css
.box {
  position: relative;
  z-index: 10;
}
```

`z-index` 只在定位/层叠上下文中按规则生效；不要靠不断加大数值。

## 五、颜色与单位

- 颜色：`#hex`、`rgb()`、`hsl()`、`oklch()`
- 单位：`px` `em` `rem` `%` `vh/vw` `ch`
- 响应式布局多用 `rem`/`%`/`flex`
