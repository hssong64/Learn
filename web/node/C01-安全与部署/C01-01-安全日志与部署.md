# C01-01 · 安全、日志与部署

## 学习目标

- 配置常见 Web 安全防护
- 做好日志与监控
- 会容器化/进程部署基础

## 一、安全清单

| 项 | 做法 |
|----|------|
| 头 | helmet 或手动安全响应头 |
| CORS | 最小放行，凭证需精确 origin |
| 限流 | express-rate-limit / 网关 |
| 解析 | 限制 body 大小 |
| 会话 | HttpOnly Cookie / 短期 JWT |
| 依赖 | `npm audit`、锁文件 |
| 密钥 | 环境变量/密钥服务 |
| 注入 | 参数化 SQL、模板转义 |

对照 `cybersecurity/doc/C02-04`、`C02-05`、`B01-02`。

## 二、日志

```javascript
import pino from "pino";
const log = pino({ level: process.env.LOG_LEVEL || "info" });
log.info({ userId }, "login");
```

- 结构化日志
- 不要记密码/Token 全文
- 请求 id 串联

## 三、优雅退出

```javascript
process.on("SIGTERM", async () => {
  await server.close();
  await db.end();
  process.exit(0);
});
```

## 四、部署

- PM2 / systemd / Docker
- 健康检查 `/health`
- 配置与镜像分离
- 只暴露必要端口

## 五、监控指标

延迟、QPS、错误率、进程内存、事件循环延迟。

2. 结构化日志 + requestId
3. 写 Dockerfile 并跑起来
