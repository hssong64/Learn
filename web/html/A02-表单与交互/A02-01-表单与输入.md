# A02-01 · 表单与输入

## 学习目标

- 写出可访问、可校验的表单
- 理解原生约束与自定义校验
- 处理文件与多步骤输入

## 一、基础结构

```html
<form action="/api/login" method="post">
  <label for="email">邮箱</label>
  <input id="email" name="email" type="email" required autocomplete="email" />
  <button type="submit">登录</button>
</form>
```

- `label` 与控件关联（`for`/`id`）
- `name` 用于提交
- `autocomplete` 帮助密码管理器

## 二、输入类型

| type | 用途 |
|------|------|
| text/password/email/number | 基础 |
| date/time/range/color | 专用 |
| file | 文件 |
| checkbox/radio | 多选/单选 |
| hidden | 不显示（仍可被改，勿当安全） |

## 三、约束

```html
<input required minlength="2" maxlength="32"
       pattern="[A-Za-z0-9_]+" title="字母数字下划线" />
```

- 原生校验只是**第一道**，服务端必须再校验
- `novalidate` 可关，需自建 UI 校验

## 四、可访问性

- 错误用 `aria-invalid`、`aria-describedby`
- 分组用 `fieldset` `legend`
- 按钮用 `button`，不要 `div` 模拟

## 五、安全提醒

- 密码框 `type="password"`
- 敏感操作二次确认
- CSRF Token（见网安 C02-04）
- 不信任任何客户端校验

## 动手练习

1. 注册表单：校验、错误提示、可访问标签
2. 文件上传：类型与大小提示（前端仅提示）
3. 用键盘完成整个表单
