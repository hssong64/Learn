# A01-01 · 文档结构与语义标签

## 学习目标

- 写出标准 HTML5 文档骨架
- 会用语义标签组织页面
- 理解可访问性与 SEO 的结构基础

## 一、文档骨架

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1" />
  <title>页面标题</title>
</head>
<body>
  <!-- 内容 -->
</body>
</html>
```

## 二、语义结构示例

```html
<header>
  <nav aria-label="主导航">...</nav>
</header>
<main>
  <article>
    <h1>标题</h1>
    <section>
      <h2>小节</h2>
    </section>
  </article>
  <aside>相关链接</aside>
</main>
<footer>版权</footer>
```

## 三、标题层级

- 一页通常一个 `h1`
- 不跳级：h1 → h2 → h3
- 样式不要靠错误标题级别

## 四、文本语义

| 需求 | 标签 |
|------|------|
| 强调重要内容 | `strong` / `em` |
| 代码/快捷键 | `code` `kbd` |
| 引用 | `blockquote` `q` |
| 时间 | `<time datetime="2026-09-30">` |
| 缩写 | `<abbr title="...">` |

## 五、列表与表格

- 一组：`ul` `ol` `dl`
- 表格仅用于表格数据：`table` `thead` `th scope` `caption`
