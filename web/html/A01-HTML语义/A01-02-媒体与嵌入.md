# A01-02 · 媒体、链接与嵌入

## 学习目标

- 正确使用图片、音视频、iframe
- 处理响应式媒体与可访问文本
- 理解安全嵌入边界

## 一、图片

```html
<img src="a.png" alt="描述性文字" width="800" height="600" />
<picture>
  <source srcset="a.avif" type="image/avif" />
  <img src="a.png" alt="描述" />
</picture>
```

- 装饰图 `alt=""`
- 内容图必须有意义的 `alt`

## 二、音视频

```html
<video controls width="640">
  <source src="a.mp4" type="video/mp4" />
  你的浏览器不支持 video
</video>
```

- 提供字幕 `track`
- 不要默认自动播放有声

## 三、链接

```html
<a href="/about">关于</a>
<a href="https://x.com" target="_blank" rel="noopener noreferrer">外链</a>
```

`target="_blank"` 必须配 `rel="noopener"`。

## 四、iframe 与嵌入

```html
<iframe src="https://player.example" title="播放器"></iframe>
```

- 必有 `title`
- 注意点击劫持与 CSP（见网络安全 C01）
- 限制 `sandbox` 属性

## 五、性能注意

- 图片尺寸与格式（webp/avif）
- `loading="lazy"` 非首屏
- 预加载关键资源 `preload`，慎用 `prefetch`

2. 给视频加字幕轨
3. 检查页面所有 img 的 alt
