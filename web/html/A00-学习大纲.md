# A00 · HTML 学习大纲

> 目标：写出语义化、可访问、对搜索引擎与辅助技术友好的 HTML。
> 前端优势：你已会写标签，这里补结构与语义的「为什么」。

---

## 一、学习目标

| 阶段 | 目标 |
|------|------|
| 语义结构 | 用正确标签表达含义 |
| 表单交互 | 表单可访问、可校验 |
| 元信息 | SEO、分享、PWA 基础 |

**阅读顺序**：A00 → A01 → A02 → B01

---

## 二、模块

| 前缀 | 内容 |
|------|------|
| A01 | 文档结构与语义标签 |
| A02 | 表单与交互元素 |
| B01 | 无障碍、SEO、元信息 |

---

## 三、速查：什么时候用什么标签

| 场景 | 标签 |
|------|------|
| 页头/导航/主区/页脚 | `header` `nav` `main` `footer` |
| 独立内容 | `article` |
| 页面区块 | `section`（需有标题） |
| 补充 | `aside` |
| 按钮动作 | `button` |
| 跳转链接 | `a` |

---

## 四、与 CSS/JS 的边界

- HTML：结构与含义
- CSS：外观
- JS：行为  
不要用 `div/span` 硬堆一切；语义对无障碍和爬虫是刚需。
