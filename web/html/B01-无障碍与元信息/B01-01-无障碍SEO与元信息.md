# B01-01 · 无障碍、SEO 与元信息

## 学习目标

- 掌握 WCAG 常用原则
- 配置 SEO 与分享元信息
- 用工具检测可访问性

## 一、可访问性要点

| 原则 | 做法 |
|------|------|
| 可感知 | alt、字幕、对比度 |
| 可操作 | 键盘可达、焦点可见 |
| 可理解 | 清晰文案、一致导航 |
| 稳健 | 语义 HTML、有效 ARIA |

```html
<button aria-label="关闭">X</button>
<nav aria-label="主导航">
<div aria-live="polite">结果已更新</div>
```

**优先语义 HTML，ARIA 是补丁不是替代。**

## 二、SEO 基础

```html
<title>独特且描述性的标题</title>
<meta name="description" content="一句话摘要" />
<link rel="canonical" href="https://example.com/page" />
<meta name="robots" content="index,follow" />
```

- 一个页面一个 h1
- 可抓取的真实文本
- 合理的内链与 sitemap

## 三、社交分享

```html
<meta property="og:title" content="标题" />
<meta property="og:description" content="摘要" />
<meta property="og:image" content="https://.../cover.png" />
<meta name="twitter:card" content="summary_large_image" />
```

## 四、视口与移动端

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
```

## 五、检测工具

- Lighthouse
- axe DevTools
- 键盘走查
- 屏幕阅读器抽测（NVDA/VoiceOver）

2. 用 axe 修 5 个可访问性问题
3. 对比度检查按钮与文本
