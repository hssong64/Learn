## 三、Markdown 报告模板

```python
def render_report(title: str, rows: list[dict]) -> str:
    lines = [f"# {title}", ""]
    lines.append("| 列 | 值 |")
    lines.append("|----|----|")
    for r in rows:
        lines.append(f"| {r['k']} | {r['v']} |")
    return "\n".join(lines)
```
