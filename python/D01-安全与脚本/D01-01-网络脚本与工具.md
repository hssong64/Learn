## 一、HTTP 探针

```python
import requests

def probe(url: str, timeout: float = 3.0) -> dict:
    try:
        r = requests.get(url, timeout=timeout, allow_redirects=False)
        return {"url": url, "status": r.status_code, "len": len(r.content)}
    except requests.RequestException as e:
        return {"url": url, "error": type(e).__name__}
```

## 二、端口探测（概念，靶场）

```python
import socket
def is_open(host, port, timeout=1.0) -> bool:
    try:
        with socket.create_connection((host, port), timeout=timeout):
            return True
    except OSError:
        return False
```

控制并发与速率，避免影响业务。
