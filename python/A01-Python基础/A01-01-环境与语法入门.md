# A01-01 · 环境与语法入门

## 学习目标

- 配好 Python 3.11+ 与 venv
- 掌握变量、类型、输入输出、缩进
- 写出可运行脚本

## 一、环境

```bash
python --version
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/Mac: source .venv/bin/activate
pip install requests
pip freeze > requirements.txt
```

建议：uv 或 poetry 管理依赖（项目变大后）。

## 二、Hello

```python
def main():
    name = input("your name: ")
    print(f"hello, {name}")

if __name__ == "__main__":
    main()
```

- 缩进即语句块（4 空格）
- `if __name__ == "__main__"` 可被 import 而不执行

## 三、类型与运算

```python
x: int = 1
s: str = "hi"
ok: bool = True
f: float = 1.5
data = None
```

```python
n = int(input())
a, b = 1, 2
print(a + b, a / b, a // b, a % b)
```

类型提示推荐写全，便于 IDE 与阅读。

## 四、格式化

```python
name = "tom"
print(f"name={name}, {1+1=}")
```

优先 f-string。

## 五、风格（PEP 8）

- 小写下划线命名 `user_name`
- 模块 `my_module.py`
- 包名小写
- 每个函数做一件事
