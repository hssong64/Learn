# A01-02 · 流程控制与模式匹配

## 学习目标

- 熟练 if/for/while、推导式
- 会用 match（3.10+）
- 能写清晰的分支逻辑

## 一、条件与循环

```python
if score >= 90:
    level = "A"
elif score >= 60:
    level = "B"
else:
    level = "C"

for i in range(5):
    print(i)

while True:
    line = input()
    if line == "quit":
        break
else:
    ...
```

## 二、推导式

```python
squares = [x * x for x in range(10)]
evens = [x for x in nums if x % 2 == 0]
m = {k: v for k, v in pairs}
s = {x % 3 for x in nums}
```

可读则用，过长则写普通循环。

## 三、match（结构化模式匹配）

```python
match cmd:
    case "start":
        start()
    case "stop" | "quit":
        stop()
    case _:
        print("unknown")
```

## 四、常用控制

```python

    ...
```
