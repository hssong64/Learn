# E01-01 · Python 练习路径与项目

## 学习目标

- 有明确练习与项目产出
- 能写出可维护的 CLI 工具
- 知道进阶方向（数据/后端/安全）

## 一、练习路径

```text
L1 小脚本：文件、字符串、JSON
L2 CLI 工具：argparse/typer + logging + tests
L3 网络工具：requests + 并发 + 报告
L4 项目：完整 README 与打包
```

## 二、推荐项目

**Lab Report Toolkit（实验报告工具箱）**

| 模块 | 功能 |
|------|------|
| ingest | 读取 JSONL/CSV |
| analyze | 统计、简单规则检测 |
| report | Markdown/HTML 输出 |
| cli | 子命令 `analyze` / `report` |
| tests | pytest |

## 三、CLI 示例骨架

```python
import typer
app = typer.Typer()

@app.command()
def analyze(path: str):
    """分析输入文件"""
    typer.echo(f"analyzing {path}")

if __name__ == "__main__":
    app()
```
