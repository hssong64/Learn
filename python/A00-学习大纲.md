# A00 · Python 学习大纲

> 面向对象：有前端/编程基础，想用 Python 做脚本、自动化、爬虫与安全工具。
> 目标：写出清晰 Python → 会标准库与虚拟环境 → 能做爬虫/自动化 → 能写安全向小工具并有项目产出。

---

## 一、学习目标

| 阶段 | 目标 | 完成标志 |
|------|------|----------|
| 语法（1 周） | 类型、流程、函数、数据结构 | 能写 100 行内小脚本 |
| 模块化（1 周） | 类、模块、包、异常 | 能组织多文件项目 |
| 标准库（1 周） | pathlib、json、re、datetime、threading | 能做文件批处理 |
| 应用（2 周） | requests、爬虫、自动化 | 能抓取并清洗数据 |
| 安全向（1–2 周） | 网络、解析、报告脚本 | 能写信息收集/验证辅助 |
| 实战（持续） | 项目 | 1 个可展示项目 |

## 四、与前端/安全的衔接

| 你已熟悉 | Python 对应 |
|----------|-------------|
| JSON | `json` 标准库 |
| 异步 | `asyncio`（进阶） |
| npm 脚本 | `pip` + `typer`/`click` CLI |
| Fetch | `requests` / `httpx` |
| 正则 | `re` |
| 自动化测试思路 | pytest |

在网安学习中，Python 是 Burp/SQLMap 之上的**定制脚本层**。
