# B02-01 · 类、模块与包

## 学习目标

- 会写简洁的 Python 类
- 会组织模块与包
- 能管理依赖与入口

## 一、类

```python
from dataclasses import dataclass

@dataclass
class User:
    name: str
    age: int

    def adult(self) -> bool:
        return self.age >= 18
```

优先 `dataclass` / `pydantic` 减少样板代码。

## 二、继承与多态

```python
class Animal:
    def speak(self) -> str: ...
class Dog(Animal):
    def speak(self) -> str:
        return "wang"
```

鸭子类型：有相应方法即可用，不强制继承。

## 五、异常设计

```python
class AppError(Exception):
    pass
```

库抛具体异常，CLI 层统一转用户可读错误。
