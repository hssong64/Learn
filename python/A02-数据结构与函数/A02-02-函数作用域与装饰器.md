# A02-02 · 函数、作用域与推导

## 学习目标

- 会写带类型提示的函数
- 理解作用域、闭包、装饰器入门
- 会用参数解包与返回值设计

## 一、函数定义

```python
def add(a: int, b: int) -> int:
    return a + b

def greet(name: str, *, greeting: str = "hi") -> str:
    return f"{greeting}, {name}"

def total(*nums: int, **meta: object) -> int:
    ...
```

关键字参数用 `*` 强制；`**kwargs` 谨慎使用。

## 二、默认值陷阱

```python
# 错误
def f(items=[]):
    items.append(1)
    return items

# 正确
def f(items=None):
    if items is None:
        items = []
```

## 三、作用域与闭包

```python
def counter():
    n = 0
    def inc():
        nonlocal n
        n += 1
        return n
    return inc
```

## 四、装饰器入门

```python
import functools
def log(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print("call", func.__name__)
        return func(*args, **kwargs)
    return wrapper

@log
def work():
    ...
```

常用于日志、鉴权、缓存、重试。

## 五、生成器

```python
def gen(n):
    for i in range(n):
        yield i * i
```

惰性求值，适合大文件/大序列。
