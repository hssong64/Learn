# A02-01 · 列表、字典与常用结构

## 学习目标

- 熟练 list/dict/set/tuple
- 理解可变与不可变
- 会选对结构写出高效代码

## 一、列表

```python
a = [1, 2, 3]
a.append(4)
a.extend([5, 6])
a.insert(0, 0)
a.remove(2)
a.pop()
a.sort(reverse=True)
b = a[:2]  # 切片拷贝视图逻辑要懂
```

## 二、字典

```python
d = {"a": 1}
d.get("b", 0)
d.setdefault("c", 3)
d.update({"d": 4})
for k, v in d.items():
    ...
```

## 三、集合与元组

```python
s = {1, 2, 2, 3}  # 去重
t = (1, 2)        # 不可变，可作 dict 键
```

| 结构 | 有序 | 可变 | 用途 |
|------|------|------|------|
| list | √ | √ | 序列 |
| tuple | √ | × | 固定集合/键 |
| dict | 插入序 | √ | 映射 |
| set | × | √ | 去重/集合运算 |

## 四、深浅拷贝

```python
import copy
b = a          # 同一对象
c = a.copy()   # 浅拷贝
d = copy.deepcopy(a)
```

嵌套可变结构用 `deepcopy` 慎重评估。

## 五、排序

```python
sorted(users, key=lambda u: u["age"], reverse=True)
users.sort(key=lambda u: u["age"])
```
