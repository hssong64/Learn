## 一、并发选型

| 场景 | 方案 |
|------|------|
| IO 密集（网络/磁盘） | asyncio / ThreadPool |
| CPU 密集 | ProcessPool |
| 简单并行任务 | `concurrent.futures` |

```python
from concurrent.futures import ThreadPoolExecutor
with ThreadPoolExecutor(8) as ex:
    results = list(ex.map(fetch, urls))
```

## 二、logging

```python
import logging
logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s")
log = logging.getLogger(__name__)
log.info("start")
```

不要裸 `print` 上生产脚本。

## 三、pytest

```python
# test_add.py
from app import add

def test_add():
    assert add(1, 2) == 3
```

```bash
pytest -q
```

- 测试文件 `test_*.py`
- 断言用 `assert`
- fixture 管理资源
