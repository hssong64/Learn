# B01-01 · pathlib、json、re 与 datetime

## 学习目标

- 用标准库做文件与数据处理
- 会写可靠的路径/时间处理代码
- 能解析常见格式（JSON/CSV/正则）

## 一、pathlib

```python
from pathlib import Path

p = Path("data") / "a.json"
p.exists()
p.read_text(encoding="utf-8")
p.write_text("{}", encoding="utf-8")
for f in Path("logs").glob("*.log"):
    print(f.name)
```

优先 `pathlib` 而非 `os.path`。

## 二、json / csv

```python
import json, csv

data = {"a": 1}
Path("a.json").write_text(json.dumps(data, ensure_ascii=False, indent=2), encoding="utf-8")

with Path("a.csv").open("r", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        print(row["id"])
```

## 三、正则

```python
import re
m = re.search(r"\d+", text)
codes = re.findall(r"flag\{[^}]+\}", text)
new = re.sub(r"\s+", " ", text)
```

先写清模式，再优化性能；复杂解析用库而非巨型正则。

## 四、datetime

```python
from datetime import datetime, timedelta
now = datetime.now()
text = now.strftime("%Y-%m-%d %H:%M:%S")
dt = datetime.strptime(text, "%Y-%m-%d %H:%M:%S")
week_ago = now - timedelta(days=7)
```

时区优先 `zoneinfo`。
